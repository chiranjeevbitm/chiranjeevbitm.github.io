    Yes, you can build this. Here is the fine print.

    The supported route is to run Anthropic's own Claude Code program on a small server, signed in as you. Everything else in this plan hangs off that one decision.

    Works today

    • Claude Code runs on a server with your own plan.Sign in over SSH with /login, or create a one-year token with claude setup-token for scripts and CI. Anthropic's terms allow signing in to the unmodified program with your own subscription.
    • You can text it from Telegram.Channels is an official plugin system for Telegram, Discord and iMessage. It is a research preview, and the session has to stay open on the server.
    • Jobs can run with your laptop closed.Cloud scheduled tasks run on Anthropic's servers on a schedule, on a GitHub event or on an API call. The shortest repeat is one hour.
    • Deploy tools already exist.Vercel and Render both publish official MCP servers, and GitHub work goes through the gh command line.

    Read before you build

    • Around the clock means reachable, not unlimited.Plan limits assume ordinary individual use, and the agent shares them with your own daily sessions. Heavy nonstop workloads belong on API billing.
    • OpenClaw and Hermes are shaky on a plan login.Anthropic cut third-party agent tools off from subscriptions on 4 April 2026 and the rules have shifted since. Budget for an API key if you go that way.
    • The 12-month free EC2 is gone for new AWS accounts.Accounts opened since 15 July 2025 get $100 to $200 in credit and a free plan that closes after six months.
    • Micro instances are too small.Claude Code asks for 4 GB of RAM. The classic free-tier micro sizes have 1 GB.

    Sources: Claude Code docs on authentication, legal and compliance, channels and cloud scheduled tasks; The Next Web on the April change; AWS free tier changes.

    The open-source shelf

    A skill is a folder with a SKILL.md playbook the agent loads when a task matches. The format is an open standard, so the same skill works in Claude Code, Codex, Cursor and Gemini CLI.

      Vet before you install. Snyk scanned 3,984 public skills in February 2026: 13.4% had a critical issue and 76 carried confirmed malicious payloads. A skill runs with everything your agent can reach. Read the playbook and its scripts first, and prefer official or well-known authors. Snyk's report
